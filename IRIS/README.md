Iris Flower classification


This research employs machine learning techniques and data analysis to categorize Iris flowers into separate species based on sepal and petal measurements. The Iris dataset, which includes three basic species - setosa, versicolor, and virginica - forms the basis for this categorization effort. Data exploration, preprocessing, and the use of several classification models, such as Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine, are all part of the project. Each model is trained and evaluated, and the most accurate one is chosen for the task. The project also uses data visualization techniques such as bar graphs and scatter plots to provide insights into species counts and feature correlations, making it an excellent starting place for people new to machine learning and classification jobs.
